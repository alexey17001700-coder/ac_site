# КлиматПро — сайт-визитка по продаже и установке кондиционеров

Одностраничный сайт для клиентов: каталог моделей, калькулятор мощности, услуги, цены, отзывы, FAQ и форма заявки.

## Что внутри

- **Шапка** — липкое меню, телефон, кнопка «Замер бесплатно».
- **Герой** — заголовок, преимущества, статистика, анимированная карточка кондиционера.
- **Каталог** — 6 моделей (Ballu, Hisense, Electrolux, LG, Mitsubishi, Daikin) с ценами «под ключ».
- **Калькулятор мощности** — считает кВт по площади, высоте потолка, солнечной стороне, людям и технике, подбирает класс BTU.
- **Услуги** — 6 карточек полного цикла.
- **Как работаем** — 4 шага.
- **Цены** — прайс на монтаж и сервис.
- **Отзывы** — 3 карточки.
- **FAQ** — аккордеон, 6 вопросов.
- **Заявка** — форма, отправляет данные в WhatsApp.
- **Адаптив** — телефон, планшет, десктоп.

## Панель администрирования (admin.js)

На сайте есть встроенная админка — править текст и каталог можно без программиста.

**Вход:** кнопка **⚙** в правом нижнем углу (или открой сайт с `?admin=1` в адресе).
**Пароль по умолчанию:** `climatepro` — смени его в «⚙ Настройки».

**Что можно делать:**

| Действие | Как |
|---|---|
| Изменить любой текст | Клик по тексту в режиме редактирования и печать |
| Поменять модели местами | Кнопки **▲ ▼** на карточке в каталоге |
| Изменить модель | **✎** на карточке: бренд, название, характеристики, цена |
| Дублировать / удалить / скрыть | **⧉** / **🗑** / **👁** |
| Добавить новую модель | Кнопка «➕ Добавить модель» в нижней панели |
| Переместить целый блок | **▲ ▼** сверху справа у раздела (Герой, Каталог, Цены…) |
| Скрыть блок | **👁** у раздела |
| Телефон, WhatsApp, почта, название фирмы | Кнопка «⚙ Настройки» |
| Настройки сохранить на постоянку | «⬇ Скачать JSON» → файл `content.json` отдать Архитектору |

**Важно:** правки хранятся в браузере (localStorage) этого устройства. Чтобы изменения увидели все клиенты — нажми **«⬇ Скачать JSON»** и пришли файл: он публикуется в репозиторий как `content.json`, и сайт подхватывает его автоматически.

## Что заменить перед запуском

Всё меняется через админку (⚙). Вручную, если нужно, — в `index.html`:

1. **Телефон** — `+79991234567` и `+7 (999) 123-45-67` (шапка, контакты, футер).
2. **Почта** — `info@climatepro.ru`.
3. **Название** — «КлиматПро» и логотип `❄`.
4. **Цены и модели** — в блоках `.card` и `.price-row`.
5. **Номер WhatsApp** — now берётся из настроек админки (`window.ACSITE.settings.whatsapp`), значение по умолчанию в скрипте формы.

## Технически

Два файла: `index.html` (весь сайт) и `admin.js` (панель администрирования). Без библиотек и сборки — чистый HTML, CSS, JS. Работает на любом хостинге и на GitHub Pages. Периодически можно положить рядом `content.json` — админка подтянет его как опубликованную версию контента.
